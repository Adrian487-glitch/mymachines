Hva er Git?

Nyttige Git-kommandoer

git initLager et nytt Git-repository i mappen du jobber i.
git statusViser hvilke filer som er endret.
git add .Legger endrede filer klare for neste commit.
git commit -m "melding"Lagrer en ny versjon av prosjektet.
git pushSender commits til for eksempel GitHub.
git pullHenter de nyeste endringene fra et eksternt repository.

Introduksjon til Git

Git er et versjonskontrollsystem. Det brukes for å holde oversikt over endringer i filer, spesielt når man programmerer.

Når du bruker Git kan du lagre forskjellige versjoner av prosjektet ditt. Hvis du gjør en feil, kan du derfor se tilbake på tidligere versjoner.

Git gjør det også enklere for flere personer å jobbe på det samme prosjektet uten å overskrive hverandres arbeid.

Bruk av Git i Visual Studio Code

VS Code har innebygd støtte for Git. På venstre side finner du Source Control.

Her kan du se hvilke filer som er endret, velge filer som skal legges til i en commit og skrive en commit-melding.

Du kan også bruke terminalen i VS Code og skrive vanlige Git-kommandoer som:

git status
git add .
git commit -m "Oppdatering"
git push

Dette gjør at du kan bruke Git uten å forlate VS Code.

Git Bash

Git Bash er en terminal som følger med Git for Windows.

Den lar deg skrive Git-kommandoer og mange Bash-kommandoer direkte i terminalen.

Det kan være nyttig fordi mange guider for Git bruker terminalkommandoer.

GitHub

Hva er GitHub?

GitHub er en nettside og tjeneste som brukes til å lagre Git-prosjekter på internett.

Git og GitHub er ikke det samme. Git er selve versjonskontrollsystemet, mens GitHub er en tjeneste som kan lagre Git-repositories.

På GitHub kan utviklere dele kode, samarbeide på prosjekter, rapportere feil og se tidligere versjoner av et prosjekt.

Et prosjekt på GitHub ligger vanligvis i et repository, ofte forkortet til repo.

Hva er en .md-fil?

En fil som slutter på .md er vanligvis skrevet med Markdown.

Markdown er en enkel måte å formatere tekst på uten å bruke HTML.

På GitHub brukes ofte en fil som heter README.md. Den brukes til å forklare hva et prosjekt er og hvordan det brukes.
